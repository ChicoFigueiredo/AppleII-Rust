# Manual do AppleII-Rust

Este é o manual do usuário do **AppleII-Rust**, uma reescrita em Rust do emulador de Apple II [AppleWin](https://github.com/AppleWin/AppleWin) para Windows, Linux e macOS. A estrutura segue a ajuda (CHM) do AppleWin, adaptada ao que este programa realmente faz. Onde um recurso do AppleWin ainda não existe aqui, o texto diz isso com todas as letras; a lista completa está em "Diferenças em relação ao AppleWin".

17. Impressora virtual

Pressione **F1** a qualquer momento para abrir este manual dentro do emulador. Use o campo de busca para localizar um termo e o sumário à esquerda para saltar entre os capítulos. Pressione F1 de novo para fechar.

Os termos técnicos seguem o glossário do projeto (`GLOSSARY.md`): Modelo, Máquina, Ciclo, Quadro, Carta, Slot, Soft switch e assim por diante.
